## 1. 使用范围（硬边界）

本工具**只允许**用于以下内容：

- 用户**本人发布**的视频
- 用户**已获得明确授权**保存、转写、二次使用的视频
- 公开可访问、且平台规则允许保存的内容

**禁止**用于：

- 下载、转写他人未授权的原创内容后做二次发布、搬运、洗稿
- 私密、付费、已删除、仅好友可见的内容
- 批量抓取他人账号内容（无论是否商用）
- 规避平台限流、封禁、地域限制
- 任何违反《著作权法》《信息网络传播权保护条例》及平台服务协议的用途

分发者应在交付时向使用者明示上述边界，不得以「工具能力」替代「使用授权」。

## 2. 技术依赖的固有风险

| 依赖 | 性质 | 风险 |
|---|---|---|
| 腾讯元宝解析接口 | **非官方公开 API**，为腾讯网页前端内部调用 | 随腾讯改版随时可能失效，无预告、无 SLA |
| 视频号 CDN 直链 | 含时效性 token，通常数小时内过期 | 直链失效需重新解析，不构成故障 |
| 元宝登录态 Cookie | 用户本人微信扫码产生，存本机 | 会过期，需重扫；不得转借、共享、上传 |
| SenseVoice 模型 | 第三方开源模型（sherpa-onnx 转换版） | 识别存在同音字错误，不保证逐字准确 |

**据此，分发者不得对外承诺：**

- 「永久可用」「官方支持」「稳定不掉」
- 「100% 准确」「可直接作为正式文稿」
- 「免登录」「零配置」「什么都不用装」

**应如实表达为**：基于腾讯元宝的非官方解析路径，随接口变化可能失效；识别为本地离线模型，存在同音字误差，重要内容需人工校对。

## 3. 数据与隐私

| 数据 | 存放位置 | 是否离开本机 |
|---|---|---|
| 元宝登录 Cookie | `~/.workbuddy/credentials/yuanbao_state.json` | 否 |
| 视频号分享链接 | 内存 | **是**（发给腾讯元宝解析） |
| 视频文件 / 音频 | 本机临时目录，转写完自动删除 | 否 |
| 逐字稿 | 用户指定输出目录 | 否 |
| 识别模型 | `~/.cache/sph-transcript/sensevoice/` | 否 |

**唯一的外发行为是「分享链接 → 腾讯元宝」**，与用户手动把链接粘贴到元宝网页版等价。

分发者与使用者均不得：

- 把 Cookie 文件打包进分发包、上传网盘、提交到代码仓库
- 在日志、截图、教程中暴露视频直链（含 token）
- 将用户视频内容转发给任何第三方服务

## 5. 分发建议（给课程方）

1. **打包内容**：`sph-to-transcript/` 整个目录 + 本文件。
2. **不要打包**：任何 `*_state.json`、`*.mp4`、`*.wav`、个人 Cookie。
3. **首次交付**：口头强调「只转你自己或你获得授权的视频」，并让对方确认。
4. **模型分发**：229 MB，可放网盘；也可让学员自行 `--setup` 下载。
5. **支持口径**：出问题让学员截图反馈，不要引导其修改脚本或绕过校验。
6. **版本说明**：标注版本号与日期（当前 v2.2.0）。接口失效时便于统一更新。
