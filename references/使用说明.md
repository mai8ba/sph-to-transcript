# 视频号逐字稿 · 使用说明（学员版）

> 这个工具把**微信视频号的视频**变成**文字稿**。
> 全程免费，不用买 API，不用装付费软件。只需要一开始扫一次微信码。

---

## 一、准备（只做一次，约 3 分钟）

### 第 1 步：双击「一键准备」

打开 `sph-to-transcript` 文件夹：

- **Windows**：双击 `一键准备.bat`
- **Mac**：双击 `一键准备.command`

会弹出一个黑色/白色窗口，自动开始干活：

1. 检查 Python
2. 装几个必需的库（自动）
3. 下载语音识别模型（**约 229 MB**，网速正常 1-2 分钟）

看到 `环境准备完成` 就好了。窗口可以关掉。

> **如果模型下载失败**：提示里会给出下载地址。用浏览器下好那两个文件，
> 放到 `C:\Users\你的用户名\.cache\sph-transcript\sensevoice\`
> （Mac 是 `~/.cache/sph-transcript/sensevoice/`）。
> 或者找已经装好的同学，把那个 `sensevoice` 文件夹整个拷过来。
> 也可以让同学打包成 zip，然后运行 `--import-model 路径` 导入。

### 第 2 步：双击「首次登录」

- **Windows**：双击 `首次登录.bat`
- **Mac**：双击 `首次登录.command`

会弹出一个浏览器窗口，显示腾讯元宝的登录页。

**用手机微信扫屏幕上的二维码**，手机上点「确认登录」。

看到 `登录成功` 就完成了。这个登录状态能管很久，**不用每次都扫**。

> 如果窗口里没有二维码，或者扫完没反应：关掉窗口，再双击一次。
> 2 分钟没扫码会自动超时。

## 二、出稿（每次就是这么简单）

### 方法一：跟 AI 助手说（推荐）

在 WorkBuddy 里直接说：

> 把这条视频号转成逐字稿：https://weixin.qq.com/sph/xxxxx

或者一次给多条：

> 这几条都转一下：
> https://weixin.qq.com/sph/aaa
> https://weixin.qq.com/sph/bbb

助手会自动调用这个 skill，出稿后告诉你文件在哪。

### 方法二：自己敲命令

```bash
# Windows
cd %USERPROFILE%\.workbuddy\skills\sph-to-transcript
python scripts\sph2txt.py "https://weixin.qq.com/sph/xxxxx"

# Mac
cd ~/.workbuddy/skills/sph-to-transcript
python3 scripts/sph2txt.py "https://weixin.qq.com/sph/xxxxx"
```

## 三、怎么拿到视频号链接

1. 打开微信视频号，找到那条视频
2. 点右下角**「···」**（或「分享」）
3. 选**「复制链接」**
4. 粘贴出来，形如 `https://weixin.qq.com/sph/AUnPiwzWH`

## 四、常见问题

**Q：稿子在哪？**
默认在运行命令时所在的目录下的 `逐字稿/` 文件夹。助手执行时会告诉你完整路径。

**Q：稿子长什么样？**
就是纯文字，已经按内容自动分好段，空一行一段。没有时间码、没有字幕文件、没有中间文件
——输出文件夹里只有一个 `.txt`。

**Q：段落是怎么分的？**
按你讲了几件事来分：说到「第一、第二」「首先、接下来、最后」这类词会另起一段；
说话有明显停顿（1 秒以上）也会另起一段。太长的一段会自动均分成两段，不会一大坨。

**Q：想要每段带时间码？**
加 `--timestamps`，每段前面会多一个 `[00:01:23]`，方便回原片定位。默认不加。

**Q：想要字幕文件（srt）？**
这个版本不出了。如果确实要烧字幕，把 `--timestamps` 的稿子丢给剪映的「文本导入」也能对齐。

**Q：想保留视频文件？**
你说了算。你要是只想要文字，就默认不留，转完自动删，省空间。
你要是视频也想留着，就跟我说「视频也要」，我会加 `--keep-video`，
视频就放在 `逐字稿/videos/` 里。其余过程文件（wav）一律放系统临时目录，跑完自动清掉。

**Q：给我的稿子怎么有两份？**
一份是机器原样听写的「原始稿」，一份是我帮你把错字、断句擦干净的「润色版」。
想发就发润色版，想核对原话就看原始稿。润色不额外收费，也不慢。

**Q：多久能出稿？**
7 分钟的视频约 18 秒，11 分钟约 22 秒，81 分钟直播回放约 2.5 分钟。看电脑 CPU。

**Q：稿子里有错别字？**
会有。识别模型对同音字会错，比如「反常识」可能写成「反常时」。
这是离线模型的通病。专业术语建议自己过一遍，或者把稿子丢给 AI 让它结合上下文改错。

**Q：提示「登录态已过期」？**
再双击一次 `首次登录` / `首次登录.command` 扫一次就行。

**Q：提示「该视频没有音轨」？**
那条视频只有画面没配音，转不了。

**Q：能转抖音/小红书/B站吗？**
不能，这个工具只认视频号链接。

**Q：视频会被上传到什么地方吗？**
不会。视频下载到你自己电脑，识别也在你电脑上跑，全程不出本机。
唯一联网的地方是：把**分享链接**发给腾讯元宝换取视频地址（这一步必须联网）。

## 五、能用多久

元宝的解析接口是腾讯网页内部用的，腾讯哪天改版就可能失效。
真失效了需要更新这个 skill，不是你的操作问题。

遇到报错，把**截图**发给老师，别自己乱改文件。
